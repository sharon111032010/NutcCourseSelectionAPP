# NUTC 智慧選課助手（Android App）

國立臺中科技大學（NUTC）115-1 學期日間部課程的搜尋與排課輔助 App。
可以依星期、節次找課，把課加進自己的週課表，並自動檢查衝堂、統計學分。

這不是學校的正式選課系統：不需要登入、不會送出任何選課動作，只用來查課和排課。

- 語言／介面：Java + XML Layout
- 最低支援：Android 8.0（API 26）
- 課程資料：115-1 學期，共 3,209 門課、372 個班級，打包在 App 內，離線可用

---

## 開啟與執行

1. 用 Android Studio 的 **File › Open** 開啟 `NUTCCourseApp` 資料夾
2. 等 Gradle Sync 完成（第一次需要網路下載相依套件）
3. 選模擬器或實體手機，按 ▶ Run

需要 Android Studio Koala（2024.1）以上的版本。

## 功能畫面

| # | 畫面 | 說明 |
|---|------|------|
| 1 | 啟動畫面 | 讀取課程資料 |
| 2 | 首頁 | 顯示課程總數、已選課程、學分、衝堂數，以及各功能入口 |
| 3 | 課程搜尋 | 用課名、教師、班級、課程代碼或教室搜尋 |
| 4 | 進階篩選 | 依星期、節次、必選修、系所、學制、年級、通識領域篩選 |
| 5 | 課程詳情 | 上課時段、教室、學分、人數、備註；可加入課表或收藏 |
| 6 | 依系所瀏覽 | 列出所有系所與開課單位 |
| 7 | 選擇班級 | 列出該系所的班級 |
| 8 | 班級課程 | 列出該班所有課程，可一次把必修加入課表 |
| 9 | 通識／體育／語言 | 依通識領域、體育項目等分類瀏覽 |
| 10 | 我的課表 | 週課表格子，衝堂的節次會標成紅色 |
| 11 | 衝堂檢查 | 列出所有衝堂的課程與重疊節次 |
| 12 | 已選課程與學分 | 總學分、必修／選修學分、每週時數 |
| 13 | 我的收藏 | 先收藏的課程，可找出能直接加入、不衝堂的課 |
| 14 | 設定 | 課表顯示選項、清除課表與收藏 |
| 15 | 關於 | 資料統計與使用限制 |

### 節次篩選的兩種模式

- **完整符合**（預設）：課程的所有節次都在勾選範圍內才會列出。
  例如勾選星期一第 1～2 節，「一 1-2」會列出，「一 1-3」不會。
- **有碰到即可**：只要有任何一節在勾選範圍內就會列出。

### 資料儲存

課表、收藏、篩選條件都只存在這支手機上，不需要帳號。
解除安裝 App 或清除 App 資料後就會消失。

## 資料收集

App 內的課程資料不是在手機上即時抓取的，而是事先從學校公開的選課網站爬取、整理後，
存成 `courses_1151.json` 打包進 App。

### 資料來源

學校公開課程查詢網站（日間部）：
`https://aisap.nutc.edu.tw/public/day/course_list.aspx?sem=1151`

只使用公開頁面，不需要登入。

### 爬取流程

1. **取得班級代碼清單**
   課程列表頁本身只是查詢表單，不會直接列出課程。
   所有班級代碼放在 `/public/clsno_list.js` 的 `g_Clsno` 物件中，
   key 為 `D1_{學期}`，值為 `[班級代碼, 班級名稱]` 的陣列。115-1 共 373 組。

2. **逐一查詢每個班級**
   用 `course_list.aspx?sem=1151&clsno={班級代碼}` 查詢該班的課程。
   通識、體育、語言這類跨系選修課也有自己的班級代碼，包含在同一份清單裡，不需要另外查詢。

3. **處理分頁**
   每頁最多 20 筆，課程較多的班級需要加上 `&_p=2`、`&_p=3`…繼續查詢。
   以頁面上是否有「下一頁」連結判斷是否還有下一頁。

4. **合併與去重**
   合併所有班級的課程，以課程代碼去除重複。

### 爬取時的注意事項

- **User-Agent**：網站前端有防火牆，非瀏覽器的 User-Agent 會讓連線卡住而沒有回應，
  必須使用一般瀏覽器的 User-Agent。
- **節流**：每次請求間隔約 0.5 秒並加上隨機延遲，失敗時最多重試 3 次。
  完整爬完一個學期約需 5～7 分鐘。

### 資料整理

爬下來的原始資料會先整理成 App 使用的格式：

- **上課時間**：把「星期二第５～７節 (2703)」這類字串整理成星期、節次、教室。
  一門課可能有多個時段；沒有填時間的課（如臨床實習）標記為「無固定上課時間」。
  115-1 只有 2 筆時間格式特殊（如「星期一中午時間」）無法放入課表。
- **課程名稱**：從課名中分離出學年課、併班、備註、全英語、通識領域、體育項目等標記。
- **學制與年級**：依開課班級名稱判斷（例如「護理五甲」為五專、「護理四Ａ」為二技、
  「保金四１」為四技、「企管所研二」為碩士班）。通識／體育／語言的班級不標示學制與年級。
  這只用於篩選與顯示，不代表選課資格。
- **系所**：取自班級名稱開頭（例如「資工四甲」為資工）。

### 更新資料檔

拿到新的爬取結果（JSON）後，用以下指令產生 App 使用的資料檔，再重新建置 App：

```
python3 tools/prep_courses.py courses_export.json app/src/main/assets/courses_1151.json
```

## 使用限制

- 資料為 115-1 學期的固定快照，學校之後的加開、停開、教師異動不會自動更新，
  正式資訊請以學校網站為準。
- 學制／年級由班級名稱推算，App 不會判斷你能不能修某門課。
- 本 App 非學校官方系統。
